# 📑 Contract Monthly Claim System

A **web-based application** built in **Visual Studio** using **C#** to automate the process of managing monthly claims for lecturers.  
This system provides a **centralized platform** where lecturers can submit work claims, upload supporting documents, and track approvals.

---

## 🚀 Features

### 👨‍🏫 Lecturer
- Submit claims by entering **hours worked** and **hourly rates**.
- System automatically calculates **total payments**.
- Upload supporting documents (e.g., timesheets, invoices).
- Track claim status throughout the approval workflow.

### 👔 Manager & Coordinator
- Review, verify, and approve/reject submitted claims.
- Dedicated views for managing lecturer claims.
- Ensure claims are validated before HR processing.

### 🧑‍💼 HR Department
- Manage lecturer data and approved claims.
- Process payments and generate reports/invoices.
- Provide oversight of the entire claim management process.

---

## 🛠️ Tech Stack
- **Language:** C#  
- **Framework:** ASP.NET Core MVC  
- **Database:** Entity Framework Core  
- **IDE:** Visual Studio  

---

## 📂 System Workflow
1. Lecturer submits claim → includes hours, rates, and documents.  
2. Claim moves to **Manager/Coordinator** for verification.  
3. HR processes approved claims → generates reports and invoices.  
4. Users can view additional information via the **landing page links**.

---

## 🎯 Purpose
This project streamlines the **monthly claim approval process** for universities, reducing manual paperwork and ensuring transparency across departments.
